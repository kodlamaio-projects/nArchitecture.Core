## 💻 About The Project

A project has been created that includes Advanced Repository, Dynamic Querying, JWT, OTP, Google & Microsoft Auth, Role Based Management, Distributed Caching(Redis), Logging (Serilog), Elastic Search, and much more. By contributing, you can support the project and learn new things.

## ⚙️ Getting Started

To get a local copy up and running follow these simple steps.

### Prerequisites

- .NET 10 SDK (see `global.json`)

### Installation

1. Add submodule to your backend project repository

   ```bash
   git submodule add https://github.com/kodlamaio-projects/nArchitecture.Core.git src/corePackages
   ```

- Run the following command to update this module

  ```bash
   git submodule update --remote src/corePackages
   ```

## 🚀 Usage

1. Check this [NArchitecture.RentACar](https://github.com/kodlamaio-projects/nArchitecture.Core) repository

### Analysis

1. If not, Install dotnet tool `dotnet tool restore`.
2. Run anaylsis command `dotnet roslynator analyze`

### Format

1. If not, Install dotnet tool `dotnet tool restore`.
2. Run format command `dotnet csharpier format .` (check only: `dotnet csharpier check .`)

### Tests

```bash
dotnet test
```

## 🆕 What's new in 2.0

Upgrading an existing 1.x project? Follow the [migration guide](./docs/migration-guide-2.0.md) ([Türkçe](./docs/migration-guide-2.0.tr.md)) or run `nArchGen upgrade` from [nArchitecture.Gen](https://github.com/kodlamaio-projects/nArchitecture.Gen) 2.0, which applies the mechanical steps and reports what is left.

- **.NET 10** across all packages; versions are managed centrally in `Directory.Packages.props`, shared metadata in `Directory.Build.props`.
- **MediatR removed.** The new `NArchitecture.Core.Mediator` package provides `IRequest<T>`, `IRequestHandler<,>`, `IPipelineBehavior<,>`, streaming and `AddMediator(...)`. Swap `using MediatR;` for `using NArchitecture.Core.Mediator;` and `AddMediatR` for `AddMediator`. `AddNArchitecturePipelines()` registers the standard behaviors.
- **AutoMapper removed.** `NArchitecture.Core.Test`'s `BaseMockRepository` no longer takes a mapping profile or exposes `Mapper`; use a [Mapperly](https://mapperly.riok.app/) mapper in your handlers and tests.
- **Dependencies modernized:** EF Core 10, FluentValidation 12, Swashbuckle 10 (Microsoft.OpenApi 2), `Elastic.Clients.Elasticsearch` 9 instead of NEST, AWS SDK v4, ASP.NET Core packages replaced by the `Microsoft.AspNetCore.App` framework reference.
- **Fixes:** cache group removal deletes the right `{group}SlidingExpiration` key, caches are UTF-8 end to end, `Paginate.Pages` is computed after `Count`, pipeline behaviors tolerate a missing `HttpContext`, `AddDbMigrationApplier` no longer builds a throw-away service provider and `UseDbMigrationApplier` runs inside a service scope, `IElasticSearch.GetSearchByField` actually filters by field, `UserForLoginDto`/`UserForRegisterDto` accept the password from a JSON body again (it is still never serialized).
- **Breaking:** `IElasticSearch.GetIndexList()` is now `GetIndexListAsync()`; Elastic models use `string` ids; `AddDbMigrationApplier` takes `Func<IServiceProvider, TDbContext>`; `BearerSecurityRequirementOperationFilter` expects the "Bearer" scheme to be declared with `AddSecurityDefinition`.
